# Sound Studio

Scratch の音声エディタをベースにした、ブラウザだけで動く非公式のマルチトラック音声編集ツールです。Scratch のアカウントやサーバーは不要で、音声の読み込み・編集・ミックス・書き出しまでをすべてブラウザ内で処理します。

> **非公式ツールです。** Scratch Foundation とは提携・承認関係にありません。Scratch は Scratch Foundation の商標です。

## 主な機能

### タイムライン編集

- 複数トラックの音声クリップを自由に配置（トラックは追加可能）
- トラックごとのミュート / ソロ / 音量調整
- クリップをドラッグして移動。上下のトラックへも移動できます
- クリップ左右端のドラッグでトリム
- ルーラー / レーンのクリックで再生ヘッドを移動
- 再生 / 停止、再生に合わせて動く再生ヘッド
- 吸着（スナップ）: 全トラック上のクリップの始点・終点、および 0.25 秒グリッドに吸着
- `Ctrl` / `Cmd` + スクロールで横方向にズーム（ブラウザのズームには奪われません）
- 再生ヘッド位置でクリップを分割、複製、削除
- キーボードでクリップを微調整（← / →）、トラック移動（↑ / ↓）、削除（Delete）
- クリップごとの 10 バンド EQ（31 Hz〜16 kHz、±12 dB、プリセット付き）
- クリップごとの音量と、時間に沿った音量オートメーション（グラフ編集）
- ミックスをステレオ WAV（44.1 kHz）として書き出し

### 詳細エディタ（選択中のクリップ）

- Scratch 譲りの波形編集 UI（波形表示・範囲選択・トリミング・再生ヘッド）
- 波形上でホイールを回して拡大、`Shift` + ホイールで横スクロール
- 高倍率では音量の棒ではなく、実際のサンプルのピーク波形を表示
- 再生中に波形をクリックすると、その位置へ移動して再生を継続
- スペクトラム表示（再生中にリアルタイム更新）
- 元に戻す / やり直す
- コピー / 貼り付け / 選択範囲の削除 / 別クリップとしてコピー
- エフェクト: 速く・遅く・大きく・小さく・無音・フェードイン・フェードアウト・逆再生・ロボット・エコー・ローパス・ハイパス・EQ
- 「調整」でピッチ（半音単位、-36〜+36）と音量（0〜200%）を変更
- 「フォーマット」でサンプルレートを変更（音声全体、または選択範囲のみ）
- ステレオ音声をそのまま読み込み・編集・再生

### 読み込み・出力

- WAV / MP3 / OGG / M4A / FLAC / WebM など、ブラウザがデコードできる形式を読み込み
- 読み込んだ音声のサンプルレートを表示
- タイムラインのミックスを WAV で書き出し
- 音声はすべてローカルで処理され、アップロードは行いません

## 使い方

1. 「音声を追加」から音声ファイルを読み込みます
2. クリップをドラッグして時間軸上に配置し、必要に応じて左右端をドラッグしてトリムします
3. クリップを選択すると、右側のインスペクタで EQ と音量を、下の詳細エディタで波形を編集できます
4. 「再生」でタイムライン全体を確認し、「ミックスを書き出し」で `mix.wav` を保存します

### キーボードショートカット

| 場所 | キー | 動作 |
| --- | --- | --- |
| タイムライン | ← / → | 選択クリップを 0.5 秒（吸着 OFF 時は 0.1 秒）移動 |
| タイムライン | ↑ / ↓ | 選択クリップを上下のトラックへ移動 |
| タイムライン | Delete | 選択クリップを削除 |
| 詳細エディタ | Space | 再生 / 停止 |
| 詳細エディタ | Delete / Backspace | 選択範囲を削除 |
| 詳細エディタ | Shift + Delete / Backspace | 選択範囲以外を削除 |
| 詳細エディタ | Ctrl / Cmd + Z | 元に戻す |
| 詳細エディタ | Ctrl / Cmd + Shift + Z | やり直す |
| 詳細エディタ | Ctrl / Cmd + C / V | コピー / 貼り付け |
| 詳細エディタ | Ctrl / Cmd + A | 全体を選択 |
| 詳細エディタ | Escape | 選択を解除 |

## 起動

Node.js 20 以上が必要です（`.nvmrc` は 22）。

```sh
npm install
npm start        # 開発サーバー: http://localhost:5174/
npm run build    # dist/ に本番ビルドを出力
npm run preview  # ビルド結果を http://localhost:4173/ で確認
```

## プロジェクト構成

```text
src/
  App.jsx                        # アプリのルート（タイムラインエディタ）
  index.jsx                      # React / IntlProvider のエントリポイント
  components/
    timeline/                    # タイムライン UI（トラック・クリップ・インスペクタ）
    sound-editor/                # Scratch 由来の音声エディタ UI とモーダル
    waveform/                    # 波形表示
    audio-trimmer/               # 範囲選択・再生ヘッド
    spectrum/                    # スペクトラム表示
  containers/
    sound-editor.jsx             # 音声編集の状態管理・再生・エフェクト適用
  lib/
    audio/                       # デコード、再生、リサンプル、各エフェクト
    timeline.js                  # タイムラインのモデルと計算
    timeline-mixer.js            # リアルタイム再生とオフラインミックス
    timeline-effects.js          # EQ チェーンとゲインオートメーション
public/                          # index.html / favicon
docs/ui-mockup.html              # UI 検討用の静的モック（任意）
```

## 技術スタック

- React 18
- Web Audio API（再生・エフェクト・オフラインレンダリング）
- webpack 5 + Babel
- `wav-encoder`（WAV 書き出し）
- バックエンドなし。状態はブラウザのメモリ上にのみ保持します

## 既知の制限

- プロジェクトの保存 / 読み込みは未実装です。ページを再読み込みすると内容は失われます
- マイク録音には対応していません
- ミックスの書き出しはステレオ WAV（44.1 kHz）固定です
- 長い音声や多数のトラックでは、ブラウザのメモリ使用量が増えます
